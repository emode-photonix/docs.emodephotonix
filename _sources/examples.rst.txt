
Examples
========

Quick reference for initializing, running, and closing an EMode session:

.. code-block:: python

    import emodeconnection as emc

    em = emc.EMode()                   # Launch and check out license
    em.function_name(keyword = value)  # Call EMode functions
    em.close()                         # Close and check in license

.. hardware-note-start

.. note::

   The console output on the example pages below, including all timings,
   was produced on: AMD EPYC 7763 64-Core Processor, 2 logical cores, 8 GB RAM, Ubuntu 24.04.5 LTS, x86_64 Python.

.. hardware-note-end
